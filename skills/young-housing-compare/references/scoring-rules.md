# 점수 계산 규칙 (결정론적)

이 파일은 SKILL.md에서 말하는 점수 계산을 **숫자·함수·임계값**까지 고정한다.
본문 SKILL.md는 실행 흐름과 출력 형식을 담당하고, 세부 계산은 여기 참조한다.

## 1. 처리 순서 (고정)

1. 후보 분해, 중복 제거, 그룹화, 공고 유형 태그 부여
2. 자격 상태 적용(신청 가능/불가/확인 필요)
3. 절대조건 필터 적용 → 위반 후보 제외 (상세: `references/absolute-filters.md`)
4. 월 고정비 산정(월세 + 확인된 관리비) 및 관리비 미확인 표기
5. 보증금 증액 전환 가능 조합 정리(점수 계산이 아니라 비교표용 정보로 유지)
6. 통근·역 접근성 정보 확보(Google Maps 또는 사용자 입력)
7. 점수 계산
8. 적합도 순위 결정
9. 접전 여부 판단(5.0점 이하)
10. 신청 행동 순서 별도 산정

## 2. 기본 평가 항목과 기본 가중치 (숫자 고정)

사용자가 우선순위를 따로 주지 않으면 아래 **균형형 기본 가중치**를 사용한다.
같은 입력에는 항상 같은 기본 가중치를 사용한다.

| 평가 항목 | 기본 가중치 |
|---|---|
| 통근시간 | 0.30 |
| 월 고정비 (월세 + 확인된 관리비) | 0.30 |
| 보증금 (별도 축) | 0.10 |
| 면적 | 0.10 |
| 입주 시기 | 0.10 |
| 역 접근성 | 0.10 |

- 합계 1.00.
- 우선순위가 들어오면 기본값을 덮어쓴다. 덮어쓸 때도 각 항목 점수는 아래 규칙으로 고정한다.

## 3. 항목별 점수화 규칙 (0~100점, 값이 작을수록/클수록 높은 점)

### 3.1 통근시간 (분, 작을수록 높은 점)

- 0~30분: 100점
- 31~60분: 90점
- 61~90분: 70점
- 91~120분: 50점
- 121~180분: 30점
- 181분 이상: 15점
- 미확인: 해당 항목 0점 처리하고 "통근 미확인" 표시. 통근 확정 시 순위 변동 가능성 안내.
- 통근 미확인이 많아도 통근정보 없이 순위를 확정하지 않는다.

### 3.2 월 고정비 (원, 작을수록 높은 점)

- 월 고정비 = 월세 + 확인된 관리비.
- 관리비가 미확인이면 월 고정비는 "잠정"으로 표시하고, 비용 순위는 "확정 아님"으로 표시한다.
- 점수 구간(예시, 실제 공고 범위에 맞춰 동일 규칙 적용):
  - 0~10만 원: 100점
  - 10만~20만 원: 90점
  - 20만~30만 원: 75점
  - 30만~40만 원: 60점
  - 40만~50만 원: 45점
  - 50만~60만 원: 30점
  - 60만~70만 원: 18점
  - 70만 원 이상: 10점
- 월세와 관리비를 별도 가중치 항목으로 두지 않는다. 비용 평가는 하나의 축으로만 한다.

### 3.3 보증금 (원, 작을수록 높은 점, 별도 축)

- 0~500만 원: 100점
- 500만~1,000만 원: 90점
- 1,000만~2,000만 원: 80점
- 2,000만~3,000만 원: 70점
- 3,000만~4,000만 원: 55점
- 4,000만~5,000만 원: 40점
- 5,000만 원 이상: 25점
- 보증금 증액 전환 가능 조합은 비교표에는 보여주되, 점수 계산에는 기본 보증금 기준 값을 사용한다.

### 3.4 면적 (전용면적 ㎡, 클수록 높은 점)

- 50㎡ 이상: 100점
- 40~50㎡ 미만: 85점
- 30~40㎡ 미만: 70점
- 20~30㎡ 미만: 55점
- 16~20㎡ 미만: 45점
- 16㎡ 미만: 25점
- 미확인: 해당 항목 0점 처리하고 "면적 미확인" 표시.

### 3.5 입주 시기 (빠를수록 높은 점)

- 즉시~1개월 이내 입주 가능: 100점
- 1~3개월 이내: 80점
- 3~6개월 이내: 60점
- 6개월 이상 소요 가능: 40점
- 미확인: 중간값 50점 처리 + "입주 시기 미확인" 표시.

### 3.6 역 접근성 (가장 가까운 역 도보시간 분, 짧을수록 높은 점)

- 0~5분: 100점
- 6~10분: 85점
- 11~15분: 70점
- 16~20분: 55점
- 21분 이상: 40점
- 미확인: 중간값 50점 처리 + "역 접근성 미확인" 표시.

## 4. 최종 적합도 점수 (가중합)

```
최종점수 = 통근점수×0.30 + 월고정비점수×0.30 + 보증금점수×0.10 + 면적점수×0.10 + 입주시기점수×0.10 + 역접근성점수×0.10
```

- 우선순위가 들어오면 가중치만 덮어쓴다(항목 점수 함수는 고정).
- 미확인 항목이 있으면 해당 항목 점수에 0점 또는 중간값을 적용하되, 그 사실을 반드시 표시한다.

## 5. 접전 후보 판단 기준 (수치 고정)

- 1위와 2위의 최종점수 차이가 **5.0점 이하**이면 "접전 후보"로 표시한다.
- 접전이면 다음을 함께 안내한다.
  - 통근정보가 확정되면 순위가 바뀔 수 있음
  - 관리비가 확인되면 비용 순위/전체 순위가 바뀔 수 있음
  - 보증금 증액 전환 조합을 어떻게 잡느냐에 따라 유리함이 달라질 수 있음
  - 면적·역 접근성 등의 작은 차이가 선택을 바꿀 수 있음
- 접전이어도 통근·관리비·자격 같은 핵심 정보가 미확인이면 확정 추천처럼 표현하지 않는다.

## 6. 미확인 값 처리 원칙 (고정)

- 통근시간 미확인 → 통근점수 0점, "통근 미확인" 표시, 통근 확정 시 순위 변동 가능성 안내
- 관리비 미확인 → 월 고정비 "잠정", "관리비 미확인" 표시, 비용 순위 확정 아님 표시
- 면적 미확인 → 면적점수 0점, "면적 미확인" 표시
- 입주 시기 미확인 → 중간값 50점, "입주 시기 미확인" 표시
- 역 접근성 미확인 → 중간값 50점, "역 접근성 미확인" 표시
- 자격 "확인 필요" → 점수는 계산하되 1순위 후보로 확정 추천하지 않음, "자격 확인 전제" 명시
- 자격 정보 부재 → 임의 판정 금지, 사용자에게 자격 결과 요청 또는 "확인 필요"로 둠

## 7. 동일 입력 동일 결과 원칙

- 같은 공고 자료 + 같은 자격 상태 + 같은 회사 위치 + 같은 절대조건 + 같은 우선순위가 들어오면,
  같은 기본 가중치, 같은 점수 함수, 같은 접전 기준으로 계산한다.
- 사람의 판단 개입으로 숫자를 바꾸지 않는다.
- 미확인 값은 추정으로 메우지 않고 위 규칙대로 0점/중간값으로 처리하거나 미확인 표시를 남긴다.

## 8. 보증금 증액 전환 조합의 역할

- 보증금 증액 전환 조합은 **결정 근거가 아니라 비교 정보**다.
- 점수 계산에는 기본 보증금 기준 값을 사용하고, 조합별 월 고정비 표는 비교표에 제시한다.
- 사용자가 보증금 증액 전환을 실제로 선택할지는 별도 의사결정 항목이며, 스킬은 "어떤 조합이 가능한지"까지 보여준다.

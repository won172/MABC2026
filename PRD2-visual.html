청년주택 신청자격 판정 서비스

PRD2 — 미니 PRD (Solar 에이전트 설계도)

1 한 줄 정의

청년주택 모집공고와 내 조건을 넣으면, 신청 가능 여부와 1/2/3순위 해당 여부를 빠르게 판정해 주는 서비스.

2 타깃 (WHO)

집이 필요하지만 신청 가능 여부를 몰라 기회를 놓치는 청년.

3 트리거 (WHEN)

청약 공고가 공개되고, 해당 공고에 지원하고 싶을 때.

4 입력 · 출력 (INPUT / OUTPUT)

입력

공고문 (모집공고 전문을 붙여넣기)

출력

  • 한 줄 요약
  • 신청 가능 여부
  • 1/2/3순위 해당 여부
  • 자격 판별 표
  • 신청 시 유의사항

5 필요 설정 (SETUP)

비밀 (운영자 쪽)

  • Solar API 키 — Vercel 환경변수에 숨김
  • 사용자 화면에는 보이지 않음

프로필 (사용자 쪽)

  • 사용자 조건을 저장
  • 재방문 시 다시 묻지 않음
  • 브라우저 localStorage 활용

6 해결 지점 (SOLVE)

있으면

빠르게 신청 가능 여부 판단

없던 때

공고를 일일이 읽어 직접 판단해야 했음

7 범위 밖 처리

  • 청년이 아닌데 자격판정을 요구하면 거절 / 보류 처리
  • 공고에 없는 조건으로 판정하지 않음
  • 웹 검색으로 공고 내용 보완하지 않음
  • 최종 입주자격 확정이 아니라 1차 확인임을 명시

8 구현 참고

  • Vercel 배포 공개 웹 서비스
  • 계정 없이 URL로 사용
  • 예선 스킬 youth-housing-eligibility-checker가 핵심 P0
  • Solar 호출은 백엔드 /api에서
  • 키는 환경변수에 숨김
